# Interactive report

A simple example of Progress & Compress (Schwarz et al., 2018) that runs in the browser: can the knowledge base learn task B without forgetting task A?

`index.html` is one self-contained page, no server and no dependencies. Open it in a browser, or serve the folder:

```bash
python3 -m http.server 8765 --directory interactive_report
```

then open http://localhost:8765/.

## What the page computes

Everything on screen comes from one seeded run that the page computes at load (about 1 s):

- A small two-column model with the real Progress & Compress structure: two tanh MLP columns (144 → 16 → 8), one head per task per column, adaptors α ⊙ U σ(V h + c) from the KB into the active column, 5408 parameters.
- Task A = 6 Oriya characters, task B = 6 Keble characters, 12 × 12 pixels, 2 samples each plus 3 shifted copies (48 training images per task). The predictions shown are on training images.
- Five segments on one timeline: progress on A, compress A into the KB (frozen copy of the whole network as the teacher), the diagonal Fisher of the KB on task A, progress on B, compress B with the EWC penalty and, as a ghost, without it (λ = 0).
- The λ slider recomputes the last segment. The Fisher view is a 2-D slice of the KB's parameter space through the two displayed paths, with task A's loss as contours, and a spring inset for three weights.

The equations and the per-λ numbers are in the page's "Equations and details" section. The method is the one of `src/run_omniglot.py` at toy scale; the numbers of the real experiments are in the main `README.md`.

## Files

- `index.html`: the report.
- `build_glyphs.py`: derives the glyph data (display PNGs and 12 × 12 inputs) from the Omniglot download; the page embeds the result.
- `gameplay_animation.py`: a matplotlib animation of P&C and fine-tuning learning Pong, then Boxing, on Atari. It reads `gameplay/` (the clips of `experiments/render_clips.py`: one PNG sprite sheet of 84 × 84 frames per checkpoint and a `clips.json` per learner) and writes `gameplay.gif`: `uv run interactive_report/gameplay_animation.py`. An `.mp4` output also works.
